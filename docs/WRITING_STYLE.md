# 写作风格

业主在 2026-09-29 提出：少用星号、表情一类装饰符号，"言简意赅、理性朴实，简明扼要说清事情就好"。

理由是他要读这些内容，而装饰符号让阅读变累。这不是审美偏好，是可读性问题。

## 规则

- 正文里不用装饰符号。不用星号、对勾、警告图标一类东西充当强调或分点标记。
- 强调靠语序和句子本身，不靠符号。一句话重要，就把它写成重要的话。
- 分点用普通列表标记，或者干脆写成短段落。
- 提交信息和文档注释同样适用：那里符号最多，而业主也要读。
- 结论放前面，理由跟在后面。不要先铺垫再给结论。
- 不重复已经说过的话。同一件事在一个回复里说一次。

## 适用范围

回复、提交信息、docs/ 下的文档、代码注释。

表格可以用，它本身是结构而不是装饰。引用原文时保留原文的写法。
